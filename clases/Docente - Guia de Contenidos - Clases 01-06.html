IA generativa: un LLM predice texto, no razona ni verifica. Alucinación: información falsa generada con total confianza (citas inventadas, leyes falsas, estadísticas sin origen, autores ficticios) — verificar siempre en Scholar o Redalyc. 02Arquitectura del documento profesional

Generar contenido con IA, pegarlo sin arrastrar formato, estructurarlo con estilos para el índice automático. Comentarios e historial como espacio compartido.

Crear el archivo

docs.new (rápido) · Drive → + Nuevo → Documentos · Docs → "+". Elementos clave: nombre del doc, menú de estilos, panel de navegación (Ver → Mostrar esquema), autoguardado, botón Compartir.

Pegar sin formato

Ctrl+V trae todo el formato externo. Ctrl+Shift+V (Mac ⌘+Shift+V) pega solo texto plano — regla de oro siempre que se pega de un LLM o la web.

03IA como asistente académico

Perplexity para fuentes con citas verificables + normas APA. Cierre con Gemini Notebook, que solo responde con las fuentes cargadas.

Perplexity

Un LLM genérico predice desde su entrenamiento; Perplexity (perplexity.ai) busca en tiempo real y cita cada afirmación. Regla de oro: no citar a Perplexity, verificar la fuente original. Complementa a Google Scholar (scholar.google.com). Prompt chaining: usar la respuesta de un prompt como base del siguiente.

Normas APA (7ma edición)

Tipo de fuenteFormato APA
LibroApellido, I. (Año). Título. Editorial.
Artículo/webApellido, I. (Año, día mes). Título. Sitio. URL
VideoCanal. (Año, día mes). Título [Video]. Plataforma. URL
Salida de IAEmpresa. (Año). Modelo (fecha) [LLM]. URL

Cita en el texto: paráfrasis (Apellido, año) — preferida —, textual (Apellido, año, p. XX), o autor en el texto: Autor (año). DOI al final si existe; si no, URL. Nota al pie no reemplaza la cita APA (Ctrl+Alt+F).

Gemini Notebook

RAG: busca en los documentos cargados los fragmentos relevantes antes de generar la respuesta — reduce alucinaciones sin eliminarlas. Discover Sources suma documentos nuevos como fuente antes de responder con ellos.

Arena Leaderboard

Arena (arena.ai/leaderboard, antes LMArena/Chatbot Arena) es un sitio independiente donde cualquiera compara dos respuestas de IA a ciegas y vota cuál es mejor — ranking tipo Elo por categoría de tarea, sin necesidad de cuenta. Cambia cada pocas semanas: no hay "el mejor modelo", hay uno mejor por categoría. Elegir bien no reemplaza verificar lo que dice — un modelo mejor rankeado igual puede alucinar.

04Arquitectura avanzada del documento

De "documento que se lee" a "documento que se navega": tablas, imágenes ancladas, hipervínculos internos y externos.

Tablas complejas

Contenedor semántico: agrupa información y establece jerarquías. Combinar celdas solo para encabezados de grupo (rompe ordenar/filtrar en datos). Tablas anidadas: casi nunca — más de dos niveles es un problema de diseño de la información.

Imágenes flotantes

Clic en la imagen → Ajustar texto → Opciones de imagen → Mover con el texto (no "Corregir en la página" — el error más común, deja la imagen fija sin relación con el párrafo). Redimensionar desde las esquinas, nunca desde el centro de los lados.

Hipervínculos

Externo: Ctrl+K sobre texto seleccionado — el texto visible describe el destino (excepción: DOI en bibliografía, se muestra como URL). Interno: marcador manual o título con estilo (ya es destino automático) + Ctrl+K → Encabezados y marcadores. El índice automático no se actualiza solo.

Estructura de página

Salto de página: Ctrl+Intro — nunca Enter repetido. Encabezado/pie/numeración: Insertar → Elementos de página. Nota al pie: Ctrl+Alt+F, no reemplaza la cita APA.

Glosario

Imagen flotanteAnclada a un párrafo o página, texto a los costados.
Mover con el textoLa imagen sigue al párrafo si este se desplaza.
MarcadorPunto de anclaje invisible para hipervínculo interno.
05Maquetación de alta precisión (Word de escritorio)

Cambio de herramienta: Word de escritorio, página con dimensiones fijas — requiere el programa instalado (la versión web no tiene saltos de sección).

Configuración base

Word abre en Letter por defecto — en Argentina se imprime en A4. Configurar antes de escribir: Disposición → Tamaño → A4, Márgenes Normal (2,54 cm), Vertical, "Aplicar a: Todo el documento".

Saltos de sección

TipoLo que hace
Página siguienteNueva sección en página siguiente.
ContinuoEmpieza en el mismo lugar — layouts mixtos.
Página par/imparDocumentos tipo libro.

Disposición → Saltos (no Insertar). Las columnas son propiedad de sección: primero el salto, después Disposición → Columnas.

Exportación

Archivo → Imprimir para revisar antes de exportar. Archivo → Exportar → Crear PDF/XPS → Estándar (publicar e imprimir) — siempre, si hay imágenes.

Combinación de correspondencia

Documento principal (plantilla + campos «Nombre») + fuente de datos (tabla). Tiene sentido con más de 5 destinatarios y datos ya tabulados.

06Presentaciones con IA: de borrador a entrega

El documento de las Clases 04-05 se convierte en presentación: borrador con IA, diseño visual (CRAP), exportación doble.

Buena presentación

Legibilidad · una idea por diapositiva (3-5 palabras clave) · mirar al público, no la pantalla · respetar el tiempo · citar lo que corresponda.

Diseño visual — CRAP

Contraste · Repetición · Alineación · Proximidad. Jerarquía visual = tamaño + contraste. Prueba del fondo del aula: ¿se lee de lejos? ¿una sola idea? ¿el color compite con el texto?

Generar el borrador con IA

Gamma (gamma.app, gratis con créditos limitados) y Gemini Notebook Studio (gratis) — comparar el mismo pedido en dos herramientas. Gemini en Slides requiere plan pago, no es la opción de esta clase.

Exportar

.pptx (exponer sin conexión) + PDF (respaldo) — nunca un solo formato.
